# CV
Данный проект посвящен решению задачи мультиклассовой классификации изображений музыкальных инструментов с применением методов глубокого обучения. В работе реализованы и сравнены две архитектуры сверточных нейронных сетей:
1. Кастомная CNN, спроектированная с нуля.
2. Модель на базе трансферного обучения (MobileNetV2 с замороженным базовым блоком).

Проект включает полный цикл разработки: предобработку и аугментацию данных, обучение моделей, визуализацию процесса обучения, анализ матрицы ошибок и разбор ошибочных предсказаний.

Цель работы
Разработать и сравнить эффективность двух подходов к классификации изображений (обучение с нуля vs трансферное обучение), оценить качество моделей на валидационной выборке и проанализировать типичные ошибки классификации для дальнейшего улучшения модели.

Датасет
- Количество классов: 10 (saxophone, flute, violin, sitar, tabla, harmonica, guitar, drum, accordion, banjo)
- Объем выборки: ~1806 изображений
  - train/: 1448 изображений
  - val/: 358 изображений
- Разрешение изображений: 128x128 пикселей
- Источник: Датасет загружен в формате .zip и распакован в рабочую директорию.
